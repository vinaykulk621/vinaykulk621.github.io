### Skills.md and agents.md

| skills.md                                                                                                                                    | agents.md                                                                                            |
| -------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| LLMs do not produce the same result all the time,so `skills.md` will define a way to get consistent output all the time                      | LLMs do not have the same personality all the time, `agent.md` tells the LLM how to think and behave |
| specific Instructions to follow when a repetitive task is asked                                                                              | a personality/way of thinking to follow                                                              |
| place in different folders such as:<br>`SKILLS/timesfm/SKILL.md`: How to use timesfm<br>`SKILLS/ARIMA/SKILL.md`: How to implement ARIMA algo | `agents.md`/`calude.md` at the root of the project dir.                                              |
