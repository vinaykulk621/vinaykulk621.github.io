TLDR; I created a TODO application using [bubbletea](https://github.com/charmbracelet/bubbletea) and i really liked it

---

This TUI has these following features:

- create a new TODO with `Ctrl+n` key
- mark an item as done using `Ctrl+d`/`Ctrl+x`
- implements [list](https://github.com/charmbracelet/bubbletea/tree/main/examples/list-default) and [textinput](https://github.com/charmbracelet/bubbletea/tree/main/examples/textinput) for TODO title and description
